# EVE Online - Insurance Analysis

This projects aims to test whether EVE Online's ship insurance system holds up financially during the game's largest wars.
The thesis question it tries to answer is: does insurance pricing that works in calm periods survive a sudden spike in claims?

The analysis reconstructs modeled insurance premiums and payouts across two time windows (2011-2015 and 2018-2022), during which the game's most destructive conflicts occured, and tracks the resulting loss ratio over time to see whether ship insurance system stayed sustainable or was overwhelmed during wartime.

Data from [EVE Ref](docs.everef.net)
